# Organic Performance Dashboard Template

A highly interactive, premium SEO and organic search analytics dashboard template built using React, TypeScript, Tailwind CSS, and Recharts.

## 🌟 Key Features

* **Interactive SVG World Map (Choropleth)**: Visualizes geographic performance. Hover over countries to see Clicks, Impressions, CTR, and Position. Click a country to filter the entire dashboard by that country.
* **Dual-Axis Trend Chart**: Dynamic Area Chart visualization for clicks and impressions over time with customizable gradient fills and interactive metric selectors.
* **Device Distribution Chart**: High-fidelity Donut chart highlighting desktop, mobile, and tablet traffic splits.
* **Dark Mode Support**: Seamless toggle between light and dark themes using custom CSS styling variables.

## 🚀 Getting Started

### Installation

Install the project dependencies:
```bash
npm install
```

### Running Locally

Start the local development server:
```bash
npm run dev
```

### Building for Production

Compile and build the production bundle:
```bash
npm run build
```
